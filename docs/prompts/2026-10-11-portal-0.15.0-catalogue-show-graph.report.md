# 0.15.0: Catalogue right-click "Show graph" — report

Task: on Emitters/Catalogue, a right-click "Show graph" on each card row opens the tenant Graph page filtered to the nodes that card's emitter emitted. The filter is a URL, not UI state. Decisions: docs/design.md 53.

## The URL shape

```
/{tenant}/graph?source={emitter name}                    page   e.g. /default/graph?source=Emitter.Terraform
/api/tenants/{tenant}/graph?source={emitter name}        API    e.g. /api/tenants/default/graph?source=Emitter.Terraform
```

- `source` is the card's name, URL-encoded with `encodeURIComponent`. A card name is dotted ASCII, so it is sent as written.
- The match is exact and case-sensitive. A missing or empty `source` means no filter.
- The chip's X links to `/{tenant}/graph`.

## Asked once, before building

The brief assumed three things the code did not have:
- There was no `GET /api/tenants/{t}/graph`.
- There was no page at `/{t}/graph`. That URL opened Graph/Explore, a screen of Canvas widgets each bound to one layer.
- No node carries `source.emitter`. A node's `source` is Graph.Node's `{tool, command, path, file, line}` list. The `{emitter, version, target, stamp}` block belongs to the envelope, one per layer.

Jerry chose **a new tenant graph**: one envelope of every mounted layer's nodes and edges. `?source=` keeps the layers whose envelope `source.emitter` matches. It is drawn on a new Graph/Nodes page at `/{t}/graph`; Explore stays at `/{t}/graph/explore`.

## Tests

**Go**, `TestTenantGraphFiltersBySourceEmitter`, over the real fixtures stamped as in `emittersPortal`:
- **Match.** Emitter.Ledger: 12 nodes, 11 edges. Emitter.Environment: 10 nodes (9 env plus the alert), 9 edges. Emitter.Agent: 12 and 11.
- **No match.** `Emitter.Terraform` (a card with no layer), `emitter.environment` (wrong case), `Graph.Emitter.FileSystem` (unstamped) and `Emitter` each return 200 with an empty envelope. An empty `source=` returns the whole graph.
- **Edge pruning.** The ledger's 9 `records` edges into Emitter.Agent's run are in the whole graph but not in `?source=Emitter.Ledger`. An edge to a node no layer holds is never served.
- **Every envelope:** it passes Graph.Node validate, no edge dangles, no node is served twice, and every node has a `stamp.layer`.
- **The roll call's `nodes`** equals the filtered count, on `listEmitters` and `getEmitter`.

## Choices made without asking (design.md 53)

- **The filter is per layer**, because the source block is per layer. A node is in `?source=X` when a layer stamped X holds it.
- **An alert layer's copies are left out, its alerts kept**, as `listNodes` does. The whole graph also includes unstamped layers.
- **An unstamped module's row** shows `nodes` 0, and Show graph is greyed with why. Its emitter page has no Show graph.
- **"Open card" is the emitter's page** `/{t}/emitters/<name>`, the only page per card. It is greyed for a no-card name or an unstamped module; Show graph still links for a no-card name.
- **The new page is Graph/Nodes**, second under Graph. Explore and `/` are unchanged, and there is no boot refusal.
- **Colours** come from the mounted layers' ontologies merged, the first Kind winning. Node clicks do nothing yet.
